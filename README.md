# disting-ex-navigator

travelers guide for navigating parallel worlds — a two-sheet navigator for the expert sleepers disting ex (firmware v1.26, disting mk4 algorithms v4.28).

- **01 · navigation** — controls, menus, single mode, dual mode, switching between them, presets + mappings, the card, expanders · fig.01 one panel two maps · fig.02 the many-worlds tree · fig.03 front panel + where things hide
- **02 · the atlas** — all 26 single-mode algorithms in depth, plus every dual-mode slot a-1 … n-8

live: https://mellotom.github.io/disting-ex-navigator/ · pdf: `disting-ex-navigator.pdf` (dark) · `disting-ex-navigator-light.pdf`

design homage to the [house of x / powers of x](https://www.marvel.com/comics/guides/1556/house-of-xpowers-of-x) data pages — designed by tom muller with jonathan hickman. not affiliated with expert sleepers or marvel. conceived by [mellotom](https://linktr.ee/mellotom).
